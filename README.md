# Model Ready (live site)

Get your 3D model ready to share: check a phone scan or AI-generated model, fix it for phones, set its real size, and see it in AR.

**Open it:** https://claudiamiranda.github.io/model-ready-site/

This repo only holds the built page, published with GitHub Pages so that AR can launch (Quick Look on iPhone, WebXR in Chrome on Android). Everything runs in the browser and nothing is uploaded. The source lives in a separate private repo.
